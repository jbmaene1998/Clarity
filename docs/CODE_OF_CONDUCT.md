# Code of Conduct

## Our Commitment

We are committed to making participation in Clarity respectful, inclusive, and constructive for everyone.

## Expected Behavior

- Be respectful and professional.
- Assume good intent and focus on ideas, not people.
- Give constructive, actionable feedback.
- Accept responsibility and correct mistakes.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks, trolling, or persistent bad-faith behavior.
- Publishing private information without consent.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct. They may remove comments, issues, commits, or pull requests that violate these standards.

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests, discussions, and other community channels connected to Clarity.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainers by opening a private security report or contacting the repository owner directly through GitHub.

All reports will be reviewed promptly and handled with discretion.
