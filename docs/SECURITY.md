# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Clarity.

## Reporting a Vulnerability

Please do **not** open public issues for security vulnerabilities.

Use GitHub's private vulnerability reporting for this repository:

1. Go to the repository page.
2. Open the **Security** tab.
3. Submit a **Private vulnerability report**.

Include:

- A clear description of the issue
- Reproduction steps
- Potential impact
- Suggested mitigation (if known)

## Response Process

Maintainers aim to:

- Acknowledge reports within 3 business days
- Triage and assess severity
- Provide a remediation plan and timeline
- Publish a fix and release notes when resolved

## Disclosure

Please allow maintainers reasonable time to investigate and patch before public disclosure.
