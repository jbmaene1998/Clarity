# Contributing to Clarity

Thanks for contributing.

## Before You Start

1. Open an issue (bug or feature) so scope is clear.
2. Keep changes focused and reviewable.
3. Ensure your work remains non-commercial per [LICENSE](../LICENSE).

## Local Setup

```bash
npm install
npm start
```

## Quality Checks

```bash
npm test
npm run build
```

## Pull Requests

1. Create a branch from `main`.
2. Add a concise description of what changed and why.
3. Include screenshots/gifs for UI changes when relevant.
4. Confirm tests/build pass before requesting review.

## Commit Style

- Use clear, imperative messages.
- Example: `Add backup import validation for malformed files`

## Security

Do not commit secrets, API keys, local data files, or installer artifacts.
